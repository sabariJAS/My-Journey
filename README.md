\# My Journey: From a Government Laptop to Building Technology



This is the story of how one government-provided laptop became the starting point of my journey into programming, algorithms, game development, APIs, AI, and software development.



I did not start with expensive hardware or a professional setup.



I started with a laptop provided for education.



That laptop gave me something much more valuable than hardware: \*\*access to technology, experimentation, and the ability to build.\*\*



\---



\## How It Started



\### A Government Laptop Changed My Direction



The laptop was originally just a device for education.



But once I started exploring what it could do, it became something else.



It became my first development machine.



From that computer, I discovered programming.



From programming, I discovered algorithms.



From algorithms, I learned how to solve problems.



From problem-solving, I started building projects.

\# Algorithms Made Me a Problem Solver



One of the biggest changes in my journey was discovering algorithms.



At first, programming was about making code work.



Later, I started asking a different question:



> What is the best way to solve this problem?



That changed the way I approached programming.



When I worked on games, I encountered problems involving movement, interactions, game logic, conditions, and different systems working together.



Solving those problems pushed me toward algorithms.



```text

Problem

&#x20;  ↓

Break It Down

&#x20;  ↓

Understand the Logic

&#x20;  ↓

Find an Algorithm

&#x20;  ↓

Implement It

&#x20;  ↓

Test It

&#x20;  ↓

Find Problems

&#x20;  ↓

Improve It

```



Algorithms became more than programming techniques.



They became a way of thinking.



They taught me to take a large problem, break it into smaller pieces, understand each part, and build a logical solution.



That way of thinking continues to influence the projects I build today.

\# 11th Grade — Building Practical Applications



\## Weather Forecast Application



After exploring game development, I started experimenting with applications that could use real-world data.



One of my projects was a weather forecast application using the \*\*OpenWeatherMap API\*\*.



This introduced me to the idea that software could communicate with external services.



I learned about:



\* REST APIs

\* HTTP requests

\* JSON data

\* API authentication

\* Data processing

\* Application interfaces

\* Real-time information



This was an important transition from experimenting with software locally to building applications that interact with external systems.
